# Puddle Parliament

> Merge raindrops into puddles and pass micro-laws before the map dries.

A local co-op puzzle game where players control raindrops that must merge into puddles and vote on small weather laws. If a puddle grows too large it floods the district, but if it shrinks too far it evaporates.

## Features
- Move raindrops and merge them into puddles on a tile map.
- Vote on micro-laws that change evaporation, flow, and flood rules.
- Balance puddle size against a dryness timer and flood zones.
- Co-op mode where two players control separate rainfall districts.

## Stack
- Phaser 3
- TypeScript
- Howler

## Getting started
```
npm install && npm run dev
```
